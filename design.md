# Evalia Design System Guidelines

Strict adherence rules:
1. Zero Emojis anywhere in UI, charts, tables, cards, PDF reports, or Excel exports.
2. Display fonts use serif light weight 300 ('EB Garamond', 'Waldenburg', 'Times New Roman'). Never bold display headers.
3. Body and interface elements use 'Inter' with subtle letter-spacing (+0.15px to +0.18px).
4. Colors: Canvas is off-white (#f5f5f5), ink primary (#292524), pure white cards (#ffffff), subtle hairlines (#e7e5e4).
5. Buttons and badges use pill geometry (border-radius: 9999px). Cards use border-radius: 16px (xl).
6. Subtle atmospheric gradient orbs (mint, peach, lavender, sky, rose) provide ambient warmth without distraction.
